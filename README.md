Задача 1.
Гипотеза Коллатца - Начните с числа n > 1. Найдите количество шагов, необходимых для достижения единицы, используя следующий процесс: если n четное, разделите его на 2. Если n нечетное, умножьте его на 3 и прибавьте 1.

Задача 2.
Найти число Пи с точностью до N знаков после запятой — введите число и попросите программу вычислить число Пи с точностью до указанного количества знаков после запятой. Ограничьте количество знаков, до которого будет вычислять программа.

Задача 3.
Найти e до N-й цифры — аналогично предыдущей задаче, но с e вместо числа Пи. Введите число, и программа выведет e с указанным количеством знаков после запятой. Ограничьте количество знаков, до которого будет работать программа.
